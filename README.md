## 🎯 Visão Geral do Projeto

### O que é?
Uma plataforma moderna de marketplace para compra e venda de veículos (carros e motos), conectando vendedores particulares e concessionárias com compradores interessados.

### 💡 Dois Casos de Uso Principais:

#### 1️⃣ **Marketplace Geral** (Conceito Original)
Plataforma aberta onde qualquer pessoa pode anunciar e comprar veículos, similar a OLX/Mercado Livre mas especializado em veículos.

**Documentação relevante**: Todos os arquivos técnicos (PLANO_PROJETO, ARQUITETURA_TECNICA, etc.)

#### 2️⃣ **White-label para Empresa Específica** (Permuta)
Versão adaptada para uma única empresa de motos/carros, oferecida em **permuta** (troca por veículo).

**Documentação relevante**: 
- [PROPOSTA_COMERCIAL.md](./PROPOSTA_COMERCIAL.md) - Proposta de permuta
- [ESTRATEGIA_APRESENTACAO.md](./ESTRATEGIA_APRESENTACAO.md) - Como negociar
- [CONTRATO_PERMUTA_MODELO.md](./CONTRATO_PERMUTA_MODELO.md) - Modelo de contrato

**Diferenças principais**:
- ✅ Marca única (sem marketplace multi-vendedor)
- ✅ Foco em B2C (empresa → consumidor)
- ✅ Escopo reduzido (sem chat, sem avaliações complexas)
- ✅ MVP em 8-12 semanas
- ✅ Pagamento via permuta (troca por moto/carro)

### Diferenciais
- 🔒 **Segurança em primeiro lugar**: Autenticação robusta, proteção contra ataques, conformidade com LGPD
- 🚀 **Performance otimizada**: SSR, cache inteligente, imagens otimizadas, CDN
- 💬 **Chat em tempo real**: WebSocket para comunicação instantânea
- 🎨 **UX excepcional**: Design moderno, responsivo e acessível
- 📊 **Sistema de reputação**: Avaliações e verificação de usuários
- 🔍 **Busca avançada**: Filtros inteligentes e salvamento de buscas
- 📱 **Mobile-first**: Experiência otimizada para dispositivos móveis

### Stack Tecnológica Principal

#### Backend
- **Framework**: NestJS (Node.js + TypeScript)
- **Database**: PostgreSQL + Prisma ORM
- **Cache**: Redis
- **Storage**: AWS S3
- **WebSocket**: Socket.io
- **Auth**: JWT + Passport

#### Frontend
- **Framework**: Next.js 14+ (App Router)
- **UI**: React + TypeScript
- **Styling**: Tailwind CSS
- **Components**: shadcn/ui
- **State**: Zustand + React Query
- **Forms**: React Hook Form + Zod

#### DevOps
- **Containerização**: Docker
- **CI/CD**: GitHub Actions
- **Hospedagem**: Vercel (Frontend) + Railway/AWS (Backend)
- **Monitoramento**: Sentry, Datadog
- **Logs**: CloudWatch / Grafana

## 🔐 Segurança

### Medidas Implementadas
- ✅ **Autenticação**: JWT com refresh tokens
- ✅ **Autorização**: RBAC (Role-Based Access Control)
- ✅ **Proteção contra ataques**: SQL Injection, XSS, CSRF, DDoS
- ✅ **Rate Limiting**: Por IP e por usuário
- ✅ **Criptografia**: TLS 1.3, bcrypt para senhas
- ✅ **LGPD Compliance**: Consentimento, direitos dos titulares
- ✅ **Auditoria**: Logging completo de ações sensíveis
- ✅ **Backup**: Automático diário com retenção de 30 dias

## 📈 Métricas de Sucesso (KPIs)

### Técnicas
- ⚡ Uptime > 99.9%
- ⚡ Page load < 2s
- ⚡ Error rate < 0.1%
- ⚡ Test coverage > 80%

### Produto
- 👥 1.000 usuários registrados (mês 1)
- 🚗 500 anúncios publicados (mês 1)
- 💬 Taxa de conversão busca → contato > 5%
- ⭐ NPS > 50

### Negócio
- 💰 CAC < LTV
- 📉 Churn rate < 5%/mês
- 📈 Crescimento MoM > 20%
